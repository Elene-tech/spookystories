# 🎃 Spooky Stories — інтерактивний урок на Хеллоуїн (B1)

Самодостатній інтерактивний урок: 3 історії з аудіо/відео, підсвіченою лексикою,
картками, квізами та квестами. Працює в будь-якому браузері, у тому числі офлайн
(після першого відкриття з локального диска).

## Вміст папки

```
index.html      — весь урок (тексти, ігри, квізи, стилі)
images/         — ілюстрації (банер + 3 історії)
audio/          — ваші записи ElevenLabs:
                  story1-ch1.mp3 … story1-ch4.mp3
                  story2-ch1.mp3 … story2-ch4.mp3
README.md       — ця інструкція
```

## Як додати відео до Story 3

1. Завантажте відео на YouTube.
2. Відкрийте `index.html` у текстовому редакторі, знайдіть угорі рядок:
   `const STORY3_YOUTUBE = "";`
3. Вставте ID відео (частина посилання після `watch?v=`):
   `const STORY3_YOUTUBE = "dQw4w9WgXcQ";`
4. Збережіть файл. Відео з'явиться на початку третьої історії.

## Варіант А: просто відкрити локально

Двічі клацніть `index.html` — урок відкриється в браузері з усім аудіо й іграми.

## Варіант Б: GitHub → Vercel (посилання для учнів)

1. Створіть репозиторій на github.com (New repository → назва, напр. `spooky-stories` → Create).
2. Завантажте в репозиторій файли (Add file → Upload files). Мінімум потрібні
   `index.html` і папка `audio/` — картинки вже всередині `index.html`, тому
   навіть без папки `images/` урок виглядатиме повністю. Важливо: `index.html`
   має бути в корені репозиторію.
3. Зайдіть на vercel.com, увійдіть через GitHub (Continue with GitHub).
4. Add New → Project → виберіть репозиторій `spooky-stories` → Deploy
   (жодних налаштувань змінювати не треба).
5. Через ~30 секунд Vercel дасть посилання виду `https://spooky-stories.vercel.app` —
   його можна кидати учням, відкривається і з телефонів.

## План уроку на 90 хвилин

Вкладка **For the Teacher** всередині уроку: хронометраж, граматика B1,
підказки щодо аудіо/відео.

## Технічні примітки

- Варіанти відповідей у всіх квізах і квестах перемішуються при кожному відкритті.
- Якщо якийсь аудіофайл відсутній, плеєр автоматично ховається.
- Google-шрифти (Creepster, Nunito) підвантажуються з інтернету; без інтернету
  текст відобразиться системними шрифтами — функціональність не постраждає.
